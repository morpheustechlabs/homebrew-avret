# Homebrew AVRET Tap

Homebrew Cask distribution for **AVRET® — Advanced Research, Editing and Testing**.

## Install

Direct installation:

```bash
brew install --cask morpheustechlabs/avret/avret
```

Or tap first:

```bash
brew tap morpheustechlabs/avret
brew install --cask avret
```

## Upgrade

```bash
brew update
brew upgrade --cask avret
```

## Uninstall

```bash
brew uninstall --cask avret
```

## Current Release

- AVRET 1.1.6
- macOS 13.5+
- Universal — Apple silicon and Intel
- Apple Developer ID signed and notarized

The cask downloads the current release from:

```text
https://github.com/morpheustechlabs/AVRET/releases/download/v1.1.6/AVRET-latest.dmg
```
